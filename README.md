# Recipe Finder

A multi-page React recipe app using Vite, React Router, Axios, and TheMealDB.

## Requirements
- Node.js 18 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Features
- Search meals by name using TheMealDB
- Recipe detail pages with ingredients and instructions
- Save/remove favourites
- Favourites persist in localStorage
- Responsive CSS and active navigation
